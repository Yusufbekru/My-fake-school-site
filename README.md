# Локальный макет дневника

Откройте `index.html` в браузере. Сборка и установка пакетов не нужны. Для GitHub Pages используйте содержимое этой папки и публикацию из корня репозитория.

Сохранены исходные стили и разметка предоставленной страницы. Скрипты оригинального сервиса, реклама и аналитика не запускаются. Ссылки не ведут в настоящий аккаунт. Работают стрелки дней, выбор даты и кнопка «Сегодня».

Период: 12 месяцев с даты открытия страницы по времени Ташкента. Понедельник–суббота: четыре первые карточки из исходного расписания, воскресенье: без уроков. Предметы и задания повторяются, настоящие оценки не рассчитываются.

ВАЖНО: исходная сохранённая страница содержит персональные данные и школьные публикации. Эта версия создана только локально. Перед публичным размещением замените персональные сведения и фотографии демонстрационными. Некоторые изображения/шрифты, отсутствующие в сохранённых файлах, могут отличаться от оригинала.
